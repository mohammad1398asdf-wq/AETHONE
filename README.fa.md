# AETHONE 🜂

**یک کلاینت VPN اندرویدی آزاد و متن‌باز، ساخته‌شده روی هسته‌ی Aether و موتور Zeptun.**

AETHONE سرویس WARP کلادفلر را به تونل کل گوشی تبدیل می‌کند و همه‌ی
قابلیت‌های هسته را در قالب تنظیماتی ساده و دوزبانه (فارسی / English) در
دسترس کاربر عادی قرار می‌دهد.

| | |
|---|---|
| ترنسپورت‌ها | MASQUE (HTTP/3 و HTTP/2)، WireGuard، Gool (وایرگارد داخل MASQUE)، Gool-Classic (وایرگارد داخل وایرگارد)، Mim (MASQUE داخل MASQUE) |
| لایه‌های اضافه | تور (۳ حالت، پل‌های خودکار)، Psiphon (آزمایشی) |
| تونل کل گوشی | موتور Zeptun (داخل پروسه با JNI) روی `VpnService` |
| بایپس ایران | فضای آی‌پی رسمی RIPE (~۱٬۹۵۵ پیشوند) + لیست دامنه‌های داخلی، قابل ویرایش در خود برنامه |
| رابط کاربری | تم روشن و تاریک، ویجت صفحه اصلی (۳ سایز)، اعلان‌های غنی، اسپلیت‌تانل برنامه‌ای |
| ایمنی | کلید قطع خودکار داخل برنامه + راهنمای Always-on سیستم |
| زبان‌ها | فارسی (پیش‌فرض) + انگلیسی |
| حداقل اندروید | ۱۰ (API 29) |

## بیلد کردن

پیش‌نیازها: **JDK 17+** (پیشنهاد: Temurin 21) و Android SDK 35.
ساده‌ترین راه، باز کردن پروژه در Android Studio به‌روز است.

```bash
./gradlew assembleDebug
```

اولین بیلد، هسته‌ها را به‌طور خودکار از ریلیزهای گیت‌هاب داخل
`app/src/main/jniLibs` دانلود می‌کند (تسک `fetchCores`):

- [Aether v2.4.0](https://github.com/CluvexStudio/Aether/releases) — arm64, armv7, x86_64
- [Zeptun v1.1.3](https://github.com/Noisemux/zeptun/releases) — کتابخانه‌های JNI

آفلاین هستید؟ با `sh scripts/fetch_cores.sh` از قبل دانلود کنید، یا با
`./gradlew fetchCores -PrefreshCores` تازه‌سازی اجباری بگیرید.

فایل APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

نسخه‌ی هسته‌ها را می‌توانید با پراپرتی گریدل قفل کنید:

```bash
./gradlew assembleDebug -PaetherVersion=v2.4.0 -PzeptunVersion=v1.1.3
```

## معماری

```
┌────────────── برنامه‌های شما ─────────┐
│                ↓                     │ TUN ساخته‌شده توسط VpnService
│      Zeptun (فضای کاربر)             │ tun2socks، قبضه DNS، fake-IP
│                ↓                     │
│     SOCKS5 · 127.0.0.1:1819          │
│                ↓                     │
│   هسته Aether (پروسه فرزند)          │ ثبت‌نام WARP و برقراری تونل
│        ↓             ↓               │
│   WARP/MASQUE    route-direct        │ ترافیک ایرانی/داخلی منطبق
│   (تونل اصلی)    (رابط واقعی)        │ از تونل بیرون می‌ماند
└──────────────────────────────────────┘
```

- **هسته Aether** به‌صورت پروسه فرزند از `filesDir/core/bin` اجرا می‌شود
  (نصب‌شده از `libaether.so` بسته‌بندی‌شده). ثبت‌نام، اسکن نقطه اتصال و
  فایل‌های هویت همه در `filesDir/core/home` نگهداری می‌شوند.
- **Zeptun** با `libzeptun-jni.so` داخل خود پروسه بارگذاری می‌شود، دسکریپتور
  TUN را می‌خواند و همه‌ی جریان‌ها را به پروکسی SOCKS5 هسته می‌فرستد.
  کال‌بک `protect()` آن جلوی حلقه‌شدن ترافیک را می‌گیرد.
- **بایپس ایران**: لیست پیشوندهای RIPE + قوانین سفارشی شما در فایل
  `routes.conf` با بخش‌های `[direct]` و `[block]` ترکیب و با فلگ `--routes`
  به هسته داده می‌شود. دامنه‌ها از پشت تونل با خواندن SNI/Host تشخیص
  داده می‌شوند.

## قابلیت‌های رابط کاربری

- **صفحه اصلی** — دکمه اتصال (مارک برند)، وضعیت، تایمر نشست، سرعت زنده
  دانلود/آپلود، لوکیشن خروجی + پرچم، پینگ، انتخابگر پروتکل
- **روتینگ** — ۴ حالت آماده (همه‌چیز / بایپس ایران / بایپس ایران + حذف
  تبلیغات / سفارشی) + ویرایشگر حرفه‌ای با همه‌ی انواع قانون هسته
  (دامنه، دامنه دقیق، کلیدواژه، عبارت باقاعده، CIDR، پورت، شبکه محلی)
- **برنامه‌ها** — اسپلیت‌تانل با حالت استثنا یا فقط-انتخابی
- **پیشرفته** — نقاط اتصال، حامل MASQUE (H3/H2)، اوپنر QUIC v2، تکه‌سازی
  ClientHello، DNS (fake-IP، قبضه)، MTU، پشته TCP، پروکسی زنجیره‌ای، ECH،
  ۱۶ تنظیم اثر انگشت TLS، Cloudflare Zero Trust، پل‌های تور، Psiphon،
  پورت‌های پروکسی محلی، محدودیت‌های هسته
- **عیب‌یابی** — لاگ زنده هسته، تست تونل، بازنشانی هویت
- **ویجت‌ها** — سه ویجت صفحه اصلی هم‌رنگ با تم برنامه
- **کلید قطع (Kill Switch)** — اگر هسته بمیرد، TUN بالا می‌ماند و همه‌چیز
  را می‌اندازد؛ به‌علاوه میان‌بر به تضمین سخت «VPN همیشه روشن» سیستم
